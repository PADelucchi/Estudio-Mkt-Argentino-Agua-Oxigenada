# Estudio-Mkt-Argentino-Agua-Oxigenada
Mediante el análisis de las estadísticas aduaneras, se estudia la evolución del mercado argentino en los últimos 5 años. Se comparan la participación del mercado de los distintos productores de agua oxigenada, así como la evolución de precios y costos logísticos. Finalmente se permiten discernir tendencias de este mercado a futuro.
